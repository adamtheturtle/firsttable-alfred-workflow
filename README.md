# First Table Cities for Alfred

An Alfred workflow that opens the newest First Table listings for:

- [Bristol](https://www.firsttable.co.uk/bristol?sort=NEWEST)
- [London](https://www.firsttable.co.uk/london?sort=NEWEST)
- [Manchester](https://www.firsttable.co.uk/manchester?sort=NEWEST)

## Installation

1. Download `Open-First-Table-Cities.alfredworkflow`.
2. Double-click it and confirm the import in Alfred.
3. Type `firsttable` in Alfred and press Return.

Alfred Workflows require the Alfred Powerpack.
